# Codex (Godot)

Jeu mobile éducatif pixel-art (RPG) pour apprendre le code de la route belge.

## Prerequisites

- Godot Engine 4.6.2 stable (minimum 4.6)

## Ouvrir le projet

1. Ouvrir Godot.
2. Cliquer sur **Import**.
3. Sélectionner `godot_project/project.godot`.
4. Lancer le projet en mode preview (orientation portrait).

## API Laravel

- Base URL: `https://api.codex.example/api/v1/`
- Documentation API: `https://api.codex.example/docs`

## UI / Font

- Police choisie: `Press Start 2P`
- Fichier: `assets/fonts/PressStart2P-Regular.ttf`
- Licence: SIL Open Font License 1.1 (OFL), voir `assets/fonts/OFL.txt`

## Conventions de code (GDScript)

- `snake_case` pour variables et fonctions.
- `PascalCase` pour les classes (`class_name`).
- `UPPER_SNAKE_CASE` pour les constantes.
- Préfixe `_` pour les membres/fonctions privés.
- Commentaires de doc `##` sur toutes les fonctions publiques.
- Typage statique systématique (ex: `var hp: int = 0`).
